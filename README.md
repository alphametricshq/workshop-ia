# Workshop de IA — Primeiro dia na academia

Bem-vindo. Se você chegou aqui, provavelmente está participando da imersão de empresários apresentada pela [Alphametrics](https://alphametrics.com.br).

## O que esse repositório é

Um roteiro passo a passo pra você **empresário** sair do zero e ter, em uma tarde, uma stack técnica funcional pra aplicar IA no seu negócio.

No fim, você vai enviar uma mensagem no WhatsApp usando um agente de IA que **você mesmo montou**.

## Como usar

1. Siga os arquivos em [`passos/`](./passos) na ordem numérica.
2. Depois de instalar o Claude Code (passo 02), rode `claude` neste diretório.
3. O Claude vai ler o arquivo [`CLAUDE.md`](./CLAUDE.md) automaticamente e passa a te guiar em português, um passo por vez.

## Estrutura

- [`passos/`](./passos) — cada arquivo é um passo do workshop, na ordem
- [`troubleshooting/`](./troubleshooting) — quando algo dá errado, procure aqui primeiro (ou pergunte pro Claude)
- [`configs/`](./configs) — templates de configuração pra copiar
- [`CLAUDE.md`](./CLAUDE.md) — instruções que o Claude Code lê automaticamente

## É só perguntar pro Claude

Se travar em qualquer passo, cola o erro no Claude e pergunta o que fazer. É esse o insight que faz tudo funcionar: **você não precisa saber, você só precisa perguntar**.
