# WhatsApp Web esta em conflito com o Evolution

## Sintoma

Ao escanear o QR do Evolution, seu WhatsApp Web desconecta. Ou o Evolution nao conecta.

## Causa

O WhatsApp so aceita **uma** sessao ativa por vez. Se voce esta logado no WhatsApp Web (navegador) ou WhatsApp Desktop, o Evolution nao vai conectar.

## Como resolver

### 1. Desconectar TODAS as sessoes

No seu celular:

1. Abre WhatsApp
2. Menu (3 pontinhos) → **Aparelhos conectados**
3. Clica em cada sessao ativa
4. Escolhe **Desconectar**

### 2. Escanear o QR do Evolution

Depois de desconectar tudo, tenta escanear o QR do Evolution de novo.

### 3. Se ainda nao conectar

- Fecha o navegador (nao so a aba — o navegador inteiro)
- Espera 30 segundos
- Tenta escanear de novo

### Depois de conectar

Enquanto o Evolution estiver ativo, seu WhatsApp Web nao vai funcionar. Isso eh normal. Se precisar do WhatsApp Web depois, so desativar a instance no Evolution.
