# Passo 07 (BONUS) — Criar site na Vercel

> Se sobrou tempo depois do momento eureka.

## O que voce vai fazer

Um site institucional simples pra sua empresa. Publicado ao vivo, com URL propria (`.vercel.app`).

## O prompt

Cola isto no seu Claude:

```
Cria um site institucional simples pra minha empresa.

- Nome da empresa: [PREENCHA]
- O que a empresa faz (1-2 frases): [PREENCHA]
- Cores/vibe da marca: [PREENCHA - se nao tiver, escolhe voce
  baseado no setor]
- Logo: [se tiver, aponta pro arquivo. Se nao, gera placeholder]
- Secoes: hero, o que fazemos, pra quem, contato

Publica na Vercel com subdominio gratis (.vercel.app).
Me mostra o link quando terminar.
```

## O que vai acontecer

O Claude vai:

1. Perguntar se voce ja tem conta Vercel — se nao, te guia pra criar (gratis)
2. Instalar Vercel CLI
3. Gerar o site (HTML/CSS/JS)
4. Fazer o deploy
5. Te dar a URL

Tempo: ~15-20 minutos.

## Depois

Voce sai do workshop com **DOIS** entregaveis: agente de WhatsApp + site publicado. E o mais importante — sabe que pode fazer mais.

Quando quiser dominio proprio (`seunegocio.com` em vez de `.vercel.app`), fala com a Alphametrics.
